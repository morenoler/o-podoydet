# Места рядом с отелями

`busan-places.json` — воспроизводимая выборка реальных открытых данных для
Хэундэ. Подготовка без сети:

```powershell
npx tsx scripts/places/build.ts
npx tsx --test tests/places-data.test.ts
```

Основные объекты извлечены из четырёх уже сохранённых
`data/osm-busan-haeundae-api-tile-*.json`. В `sources` сохранены URL/запрос,
дата получения, SHA-256 точных байтов каждого существующего кэша и атрибуция.
Исходные кэши ранее очищены от метаданных участников OSM; их SHA-256 не выдаётся
за хеш исходного HTTP-ответа до такой очистки. Даты редактирования объектов не
сохранены, поэтому `sourceDate: null`. Дата получения не заменяет дату наблюдения.

Набор неполон. Отсутствие аптеки, магазина или другого объекта в нём не доказывает
отсутствия объекта на местности. Заведения могли измениться. Для узлов используется
их точка; для полностью известного контура — среднее его вершин без повторного
замыкающего узла. Это не вход, не ближайшая граница, не пешеходный маршрут и не
подтверждение доступности. Объекты с частично неизвестным контуром исключаются.
Relations без восстановленной геометрии исключаются. Частные и явно закрытые
объекты не включаются. Продуктовый магазин не объявляется супермаркетом.

Для произвольного названия сохранены имеющиеся варианты имени на языках OSM.
`named_place` позволяет найти именованный объект, не приписывая ему одну из
специализированных категорий. `subway` требует явного признака метро.

## Что означает «центр»

У центра нет одной автоматически доказанной точки. В набор включены два
**явно выбранных ориентира**, их названия и допущения должны быть видны в ответе:

- `center:seomyeon`: станция Сомён, ориентир делового центра Пусана. Официальный
  Visit Busan описывает Сомён как крупный городской центр. Это не географический
  центр Пусана и не граница района. Координата взята из Nominatim/OSM для узла
  `5782717001`; запрос и полный небольшой JSON-ответ сохранены в
  `seomyeon-geocode.cache.json` с SHA-256 тела.
- `center:haeundae`: станция Хэундэ, выбранный приложением ориентир центральной
  части района. Координата реального узла OSM `5208472150` взята из старого кэша.
  Официальная граница центра района не утверждается.

Сомён находится за пределами основной области покрытия; добавлен только ориентир,
окружающие его заведения не выгружены. Отели каталога находятся в Хэундэ, поэтому
близость к Хэундэ не означает близость к деловому центру Пусана.

Прямой HTTPS-запрос Visit Busan не прошёл проверку сертификата; проверка TLS не
отключалась. `seomyeon-tourism.cache.json` содержит только короткую цитату из
поискового представления официальной страницы, исходный поисковый запрос и
SHA-256 этой цитаты (`evidenceKind: search_excerpt`), а не полный HTML-ответ.
Дата публикации неизвестна. Такой источник обосновывает трактовку ориентира,
а не геометрическую границу. Ссылка:
https://www.visitbusan.net/en/index.do?menuCd=DOM_000000301003001000&uc_seq=460

Разовые внешние запросы ограничивались таймаутом 15–25 секунд, размером 2 МБ,
выполнялись последовательно, без обхода ограничений. Обычная сборка и тесты
используют только сохранённые кэши и никогда не обращаются к публичным API.
