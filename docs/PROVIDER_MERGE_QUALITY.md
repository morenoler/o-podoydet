## Существенные найденные и исправленные ошибки

1. Прежняя настройка AI_PROVIDER разрешала только один модельный режим за запуск
   сервера. Добавлен registry доступных провайдеров и ограниченный областью
   HTTP-запроса выбор. Конкурентные local/DeepSeek запросы проверены раздельно.
2. Python наследовал только глобальный AI_PROVIDER. Теперь worker получает режим
   своего запуска; DeepSeek-ключ исключён из окружения local и rules.
3. Старый браузерный тайм-аут 30 секунд мог прервать 60-секундный вызов DeepSeek.
   Модельные операции имеют отдельный ограниченный срок ожидания, учитывающий два
   последовательных вызова. Отмена по AbortSignal сохранена.
4. Контрольная лабораторная проверка rules могла построить снимок через выбранный
   платный провайдер. Начальный поиск теперь получает явный rules; регрессия
   проверяет обычный и синтетический поиск при сохранённом выборе DeepSeek.
5. Выбор «Как на сервере» при server default=rules мог автоматически взять первый
   доступный модельный режим. Убрано автоматическое включение модели: один ключ
   без выбора не активирует платные запросы в лаборатории.
6. Передача сохранённого провайдера в немодельные config/catalog вызовы мешала
   восстановлению при отключении модели и могла скрыть историю. Эти вызовы,
   история, отмена и авторизация не получают заголовок выбора.
7. На мобильной странице main кнопка «Помощник» меняла состояние, но CSS скрывал
   панель без класса is-side-panel-open. Класс привязан к существующему состоянию;
   оформление не изменено. Браузерная проверка воспроизвела проблему и подтвердила
   доступность панели и переключателя после исправления.
8. Спутниковая подложка EOX/Sentinel z14 растягивалась до z19. Подробный слой
   ArcGIS использует тайлы нужного масштаба и отдельный пользовательский ключ.

Первая попытка целевых Java-тестов упёрлась в очистку системной временной папки;
повтор с workspace TEMP/TMP и java.io.tmpdir прошёл. Первый вызов window-view
из корня не нашёл Python-пакет; повтор из services/window-view прошёл 182/182.
Локальный npm.cmd из сохранённого архива имел неподходящий путь; для build:all
использован игнорируемый launcher на тот же npm-cli. Код приложения ради среды
не изменялся. Логи всех проверок находятся в `.local/`.

## Невыполненные проверки и ограничения

- Реальных запросов к DeepSeek: 0. Ключ, баланс, доступность модели, TLS-путь и
  смысловое качество ответа требуют проверки после настройки серверного ключа.
- Локальная LLM проверена на протокольном стенде, не на реальных весах Ollama.
- Авторизованные снимки ArcGIS в приложении не проверены без пользовательского
  VITE_ARCGIS_API_KEY. Без него сайт показывает OSM; это явно описано в настройке.
- Полный исторический contract runner отдельно не выполнялся; изменённый
  advisor-config snapshot дополнен новым modelNames, контракт проверен Java-тестами.
- Геометрические сценарии не подтверждают номера или этажи на месте:
  field_verified_rooms=0, unknown=14 199, outside_fov=73 353.
  SHA-256 сцены: `9a403807fcfc9db3c305b390d1bd074f3a41f12dfcf0013c91a78e8f3045a64b`.
- Числа тестов не являются процентом покрытия кода или точности сведений об отелях.
  Сообщения отельерам не отправлялись.
