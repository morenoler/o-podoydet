# Сочи: воспроизводимый каталог

В приложении добавлен второй регион, **Сочи**, рядом с Пусаном: 61 именованная OSM-запись отелей в центральной прибрежной части. Из 67 исходных записей пять без названия и одна с конфликтом текущего имени исключены. Число уникальных действующих предприятий не установлено. Выберите его в строке поиска; каталог можно открыть без дат. Даты и гости нужны для проверки требований к размещению. Карточки объектов без собранных категорий показаны отдельно от рекомендаций номеров.

Основной каталог: `data/sochi/verified-hotels.json`. Название файла и политика `verified-only` относятся к допуску доказательств о категориях; они **не означают независимую проверку существования и работы каждого отеля**. Идентичность картографических записей имеет статус `reported`.

## Источники и область

OpenStreetMap, сохранённый 24 октября 2026 года снимок центральной прибрежной части Сочи. Исходный bbox в порядке юг, запад, север, восток: `[43.565, 39.7, 43.6, 39.755]`; исходный запрос выбирал `tourism=hotel` и пляжи. Записи без собственного названия и с признаками закрытия исключаются. Отдельно 27 октября прочитаны теги [городского округа Сочи, relation 365233](https://www.openstreetmap.org/relation/365233); они не заменяют географическую область сохранённого снимка. Это каталог сохранённых записей OSM, не полный реестр рынка и не подсчёт уникальных предприятий. Возможные дубли сохранены для проверки в `quality.json`.

Центральный bbox не включает Сириус и не охватывает весь Сочи, Адлер или Лазаревское. Прямоугольник `bbox` для карты вычислен из координат объектов каталога, а не выдан за полигон муниципальной границы. Точка отеля или центр OSM-контура не подтверждает расположение входа.

`preserved-manifest.json` хранит исходные запрос, URL, дату получения, дату базы OSM, размер и SHA-256; первоначальные метаданные также сохранены без изменений. `raw/` содержит исходные байты. Финальный счётчик старого запроса описывает 2 995 пешеходных линий, а не число отелей: полнота гостиничной части независимо не доказана. `manifest.json` отдельно описывает успешно загруженные теги границы; дата её базы — 1 июня 2026 года, а не дата загрузки. Дата базы OSM, дата изменения конкретного объекта, время получения и проверка на месте различаются. У гостиниц без известной даты изменения поле `sourceEvidence.sourceDate` отсутствует. У каждой записи есть источник, `obtainedAt`, `expiresAt`, метод `osm`, статус `reported`; область свидетельства описана в `coverage`.

Сверка 16 отелей по собственным сайтам хранится отдельно: [официальные источники](SOCHI_OFFICIAL_REVIEW.md), `data/sochi/official-review.json`. Это заявления операторов о названии и адресе, с неизвестными датами обновления. Она не подтверждает категории, номера, цены или наличие. OSM-связи не угадываются по совпадению имени.

## Окружение и неизвестные условия

В сохранённом слое окружения есть шесть пляжей. Для остальных девяти типов POI сведения в этой версии отсутствуют. Определения десяти типов заданы в `place-categories.json`, но наличие определения не означает покрытие данными. Расстояние вычисляет `nearbyForSochi`: формула гаверсинуса, радиус Земли 6 371 008,8 м, округление вверх. Сохраняются входные OSM ID, координаты и версия `haversine-osm-v1`.

Ближайший объект означает ближайший среди подходящих записей данного снимка. У границы выбранного bbox и при неполной карте реальный ближайший объект может отсутствовать. Непроходимые участки, часы работы и актуальное состояние не проверены. Это расстояния по прямой; пеший маршрут, обход лестниц и путь по пляжу к воде неизвестны. Размеченного ориентира центра и данных о метро в этой версии нет.

У сочинских объектов нет выдуманных категорий, физических номеров, вместимости, цен, наличия на даты, оценок шума или утверждений о доступности. `rooms=[]`, `route=null`, `facts=[]`, `noise=[]`. Неизвестная цена не проходит ограничение бюджета. Смена региона очищает числовой бюджет, поскольку конвертация KRW/RUB не выполняется.

## Офлайн-сборка и проверки

Python 3.11+, Node.js 24+, Java 21 и Maven требуются для соответствующих частей проекта. Обычная сборка источники не обновляет:

```powershell
npm run data:prepare:sochi -- --pilot
node node_modules/tsx/dist/cli.mjs --test --test-name-pattern="small synthetic|nearby calculation|official identity" tests/sochi-data.test.ts
npm run data:prepare:sochi
node node_modules/tsx/dist/cli.mjs --test tests/sochi-data.test.ts tests/sochi-ui.test.ts
npm test
npm run backend:test
npm run build:all
```

Сначала обрабатываются пять записей, затем все 61. Проверяются хеши, размеры, исходные метаданные, структура, отсутствие вымышленных условий и точное воспроизведение JSON. Счётчик пешеходных линий не используется как доказательство полноты списка отелей. Тесты кода не заменяют сверку источников или выездную проверку. На запущенной отдельной тестовой БД/порту доступна расширенная HTTP-проверка:

```powershell
python -X utf8 scripts/verify-sochi.py --base http://127.0.0.1:8095
```

Результаты и исправления: [SOCHI_QUALITY.md](SOCHI_QUALITY.md). Основные общепроектные команды по-прежнему находятся в [README](../README.md).

## Явный сетевой сбор

```powershell
npm run data:fetch:sochi -- --lodgings-only
npm run data:fetch:sochi
```

Этот отдельный сборщик подготовлен для будущего расширения по всей административной области Сочи (area ID вычисляется как `3600000000 + relation ID`). При этой работе общегородские запросы не завершились успешно: наблюдались HTTP 502/504 и таймауты. Поэтому они не вошли в основной каталог. Сборщик не переключает релизный источник; `prepare-sochi.ts` явно использует сохранённый центральный снимок. Для включения нового источника требуется отдельная проверка и изменение функции загрузки. Сбор идёт последовательно, ограничен по времени и размеру ответа. Ошибка HTTP, структуры или счётчика останавливает процесс. Поддержаны явные `--endpoint=https://…/api/interpreter` и `--post`. Кэш не обновляется автоматически; изменение сохранённого запроса или хеша вызывает ошибку. Новую версию источников нужно сохранять отдельно и повторно проверять. Публичные серверы могут быть недоступны или иметь отстающую базу; получение сегодня не означает актуальность всех записей сегодня.

## Запуск двух регионов

Без `DATA_PATH` или при `DATA_PATH=` сервер атомарно загружает Пусан и Сочи. `DATA_PATH=data/sochi/verified-hotels.json` включает только Сочи; явные пути лаборатории и демо сохраняют один собственный набор. Используйте отдельные `DB_SCHEMA` и `UPLOADS_PATH` для проверок.

`GET /api/regions` возвращает доступные регионы и количества записей. `GET /api/catalog?region=Сочи` выбирает каталог, `trip.region` выбирает поиск и чат. Регион запроса не переключает общее состояние сервера. Неизвестный регион возвращает 400. Подробности: [server/README.md](../server/README.md).
