## Что показывает набор

Без дополнительных обязательных пожеланий проходят 5 объектов для двух взрослых,
3 для 2+1 и 2 для 2+2. Это достаточность опубликованной вместимости, не наличие свободных
номеров на даты. При обязательном семейном размещении для 2+2 проходит Shilla Ondol Suite.
Westin имеет категорию с достаточной вместимостью, но отдельное семейное условие остаётся
неподтверждённым. Grand Josun Kids Deluxe ограничивает возраст детей; без возраста
правило не разрешает автоматически размещение 2+2.

На 26–27 октября прогноз воздуха покрывает поездку, но хотя бы в одном часу AQI выше
порога 50 у всех 96 объектов. Это `mismatch`, а не отсутствие данных. На 7–8 ноября
прогноз не покрывает поездку, поэтому у 96/96 сохраняется `unknown`.

На 26–27 октября условие тишины остаётся `unknown` у всех объектов, в том числе при низком
историческом фоне. На 7–8 ноября датированное событие даёт повышенный риск у 88 объектов,
ещё 8 остаются неизвестными. Исторический фон и годовые измерения представлены с
ограничениями и не используются как доказательство тишины конкретного номера.

В реальном расчёте вида 280 целей находятся вне выбранного направления, а 40 остаются
неизвестными. Это ожидаемое ограничение данных, не 40 подтверждённых видов. Тест с двумя
этажами проверяет геометрический алгоритм на отдельной вымышленной сцене.

## Повторный запуск

Из корня репозитория после установки зависимостей и настройки Java 21:

```powershell
npm run build:all
npm run lab:build
python -X utf8 scripts/verify-http-integration.py
```

Скрипт использует порты 8080, 8081 и 8011, проверяет их доступность, копирует JAR,
генерирует отдельный лабораторный набор и создаёт базы в `.local/http-smoke/<run>/`.
Обычный запуск останавливает свои процессы после проверки, включая ошибку.
`--app-port`, `--lab-port` и `--view-port` позволяют выбрать другие порты.

Для последующей ручной проверки интерфейса есть `--keep-running`. В этом режиме после
успеха серверы остаются запущенными; PID, порты, пути к базам и логам находятся в
`processes.json` той же папки. Остановить нужно только эти процессы после проверки.

Даты поездки и исходные снимки фиксированы. Срок годности источников проверяется по
времени запуска: более поздний запуск может корректно дать другое покрытие или выявить
истёкший срок проверки категорий. Результат не оценивает локальную языковую модель,
наличие номеров, фактический шум или реальный вид из окна.
