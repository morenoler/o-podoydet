## Найденные ошибки и исправления проверки

1. После исправления области действия цены один старый тест ожидал валюту
   общей цены отеля у категории без цены. Фикстура разделена: неизвестная цена
   остаётся неизвестной, явно заданная цена категории показывается. Итог —
   352/352 frontend-теста.
2. Запуск браузера через нестандартный dev-порт 3019 получил штатный отказ
   проверки Origin на POST. Проверка перенесена на собранное приложение и API
   с одним origin `8098`; защиты запросов не менялись.
3. Первый расширенный Java-запуск столкнулся с недоступным Windows Temp.
   Путь временных файлов перенесён в `.local/` через аргумент JVM в отдельном
   проверочном POM; исходный `server/pom.xml` не менялся. Малая проверка
   AccountApiTest после этого прошла 5/5.
