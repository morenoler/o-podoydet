# Реализация MVP: Пусан / Java 21 / SQLite 3

Состояние на 24 октября 2026 года, версия 0.2.0. Реализованное поведение и проверки перечислены отдельно от возможностей полной концепции.

## Что изменилось

- Демонстрационная территория перенесена в Пусан, район пляжа Хэундэ. Исходные снимки Адлера заменены данными Пусана; старая пользовательская SQLite-база остаётся нетронутой.
- Express и TypeScript-бэкенд заменены Java 21: JDK HttpServer, Jackson, sqlite-jdbc. Maven собирает исполняемый JAR; Java обслуживает API и готовый интерфейс.
- SQLite 3 создаётся по `backend/src/main/resources/schema.sql`. Таблицы: metadata, hotels, rooms, facts, questions, drafts. Каталог после импорта читается из базы; JSON-поля сохраняют сложную геометрию и историю доказательств.
- Сохранены подбор внутри одной категории, обязательные условия, неизвестные/устаревшие/конфликтующие сведения, сравнение, кабинет отельера, предварительный разбор и атомарное подтверждение ответа.
- Сохранены ограниченные правила разбора и опциональный адаптер Responses API с проверкой цитаты и fallback. Новые параметры браузера изолированы от старой версии.
- Добавлен `scripts/assess-area.ts` с пакетным и одиночным вводом координат, кешем, тайм-аутами, проверкой единиц/времени/географии, offline-режимом и импортом официальной районной статистики.
- В карточках появился блок района. `GET /api/areas/:hotelId` читает отчёт при запросе, проверяет координаты отеля и свежесть данных воздуха. Пересборка Java для обновления отчёта не нужна.

## Данные

В снимке Хэундэ 1 714 объектов OSM; граф содержит 5 285 узлов и 22 приближённых подхода к Haeundae Beach. Выбраны 24 настоящих объекта размещения и 136 исходных фактов. Категории номеров, вместимость и ответы кабинета вымышлены и явно отмечены.

География получена из ограниченных запросов Overpass и четырёх небольших тайлов официального OSM API. Кеш региона и снимок включены в репозиторий. Маршруты идут по связанным рёбрам с учётом известных ограничений доступа. Отсутствие отмеченных ступеней не становится доказательством полной доступности. Соединительные участки от отеля до сети и от сети к точному входу на пляж не обследованы.

Для всех 24 отелей реально получены PM2.5, PM10, NO₂ и US AQI из Open-Meteo/CAMS Global. Это датированный модельный снимок с сеткой около 45 км, а не измерение конкретной улицы. Значения старше 6 часов становятся устаревшими при чтении. Выбранные даты поездки не превращают текущий снимок в прогноз.

Официальный CSV полиции содержит две используемые категории за 2025 год по всему Хэундэ-гу: кражи и разбойные нападения. Географическая привязка выполнена по полигону OSM relation 4062934; все 24 точки внутри. Период, территория, названия категорий, исходная строка/столбец, хеш CSV, методика и ограничения сохранены. Историческая граница именно за 2025 год отдельно не проверена. Из районных чисел не вычисляется личный риск или общий балл безопасности.

## Проверки

- `npm test`: 22 теста TypeScript — география, подбор на клиенте, валидация поездки, источники воздуха, географический импорт и offline CLI.
- `npm run backend:test`: 14 JUnit-проверок — HTTP-контракты, валидация, обязательные условия, область действия фактов, извлечение цитат, fallback, повторное подтверждение, конфликты, откат транзакции, повторный импорт, сохранность SQLite, координаты и свежесть отчёта района.
- TypeScript и Vite проходят сборку. Maven компилирует Java с release 21 и собирает исполняемый JAR.
- В браузере пройдено: Пусан → 5–12 ноября 2026 года → двое взрослых и ребёнок → обязательное удобство с коляской → 16 кандидатов.
- Для Geullori Condominium создан вопрос, разобран и подтверждён ответ «Перед входом три ступени, пандуса нет.». Новый подбор показал 15 кандидатов: неподходящая категория исключена. Ответ сохранён в локальной SQLite.
- В карточке проверены карта, маршрут, показатели воздуха и официальные районные сведения с источниками. Карточка и оба блока района визуально проверены в браузерном viewport 390 × 844; горизонтального переполнения не обнаружено. Это не тест на физическом устройстве.
- Независимый просмотр Java-кода проверил API, области действия, транзакции и свежесть источников. Найденный случай отсутствующего времени модели исправлен и покрыт тестом.

Во время разработки параллельная пересборка JAR нарушила загрузку классов уже запущенной JVM. Скрипт запуска теперь копирует JAR в отдельный `.local/runtime/` перед запуском. Maven принудительно пересоздаёт исходный JAR перед упаковкой зависимостей; после изменений сервер перезапущен.

## Ограничения

- Нет актуальных цен, наличия номеров, бронирования и авторизации реальных отельеров. Сервер слушает только `127.0.0.1`.
- Нет обследования маршрутов и измерения шума внутри номера. Окна во двор не гарантируют тишину.
- Скрипт оценивает загрязнение воздуха; вода, почва и санитарное состояние не измеряются.
- Нет общего рейтинга безопасности, сравнительного crime score или вероятности происшествия для гостя. Историческая статистика относится всему району и двум отдельным категориям.
- Реальный LLM-провайдер с ключом не проверен; тесты используют контролируемые ответы/ошибки.
- Полная ручная приёмка всех сценариев не заявляется. Дальнейшие проверки перечислены в [ACCEPTANCE.md](ACCEPTANCE.md).
