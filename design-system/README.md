# Визуальное направление

Основная задача — выбрать поездку и понять доказательства. Первый экран содержит регион и даты; второй — сценарии и необязательный текст.

- Палитра: бумага #f7f9fc, белый #ffffff, глубокий синий #163e8e, текст #172c4c, море #dceef4, акцент #f8b84e.
- Типографика: Golos Text с кириллицей, локальные файлы шрифта. Крупный короткий заголовок, спокойный основной текст.
- Первый экран: слева заголовок и форма, справа графическая карта побережья из реальной выгрузки. На мобильном форма идёт первой.
- Карточки выдачи: маршрут и факты вместо случайных фотографий, чёткое отделение реальных геоданных от демонстрационных условий номеров.
- Без декоративных градиентов и непрерывной анимации; статусы сопровождаются текстом, все действия доступны с клавиатуры.

Автоматическая рекомендация Aurora UI и scroll storytelling отклонена: эти паттерны не подходят пошаговому поиску. Применены рекомендации навыков frontend-design и ui-ux-pro-max по иерархии, состояниям поиска, доступности и постепенному раскрытию.

## Тестовая версия: поиск и личные кабинеты

Новые экраны включаются только сборкой `VITE_LAB_MODE=true`. Основная сборка сохраняет прежний интерфейс.

Главная страница отделяет три задачи: подобрать отель по проверенным условиям, посмотреть объявления отельеров, вернуться к своим поездкам. Реальная карта Хэундэ сохраняет контекст места; форма с датами и гостями остаётся главным действием. Шаги поиска объясняют, что произойдёт после отправки формы.

Кабинеты используют постоянную боковую навигацию: поездки / вопросы / профиль для путешественника, объявления / бронирования / вопросы / профиль для отельера. На узком экране навигация переносится над содержимым. Состояния заявки подписаны словами, а формы показывают загрузку и ошибки, сохраняя введённые значения.

Сохраняются локальный Golos Text и базовая палитра. Внешняя оболочка находится в `src/app/laboratory/laboratory.css`, поиск — в `src/features/trip/trip-search.css`, кабинеты — в собственных стилях feature-модулей. Все новые стили ограничены собственными классами. Рекомендации Aurora, анимированных градиентов и Fira Code отклонены: они не помогают работе с поездками и объявлениями.
