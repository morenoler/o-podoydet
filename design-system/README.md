# Визуальное направление

Основная задача — выбрать поездку и понять доказательства. Первый экран содержит регион и даты; второй — сценарии и необязательный текст.

- Палитра: бумага #f7f9fc, белый #ffffff, глубокий синий #163e8e, текст #172c4c, море #dceef4, акцент #f8b84e.
- Типографика: Golos Text с кириллицей, локальные файлы шрифта. Крупный короткий заголовок, спокойный основной текст.
- Первый экран: слева заголовок и форма, справа графическая карта побережья из реальной выгрузки. На мобильном форма идёт первой.
- Карточки выдачи: маршрут и факты вместо случайных фотографий, чёткое отделение реальных геоданных от демонстрационных условий номеров.
- Без декоративных градиентов и непрерывной анимации; статусы сопровождаются текстом, все действия доступны с клавиатуры.

Автоматическая рекомендация Aurora UI и scroll storytelling отклонена: эти паттерны не подходят пошаговому поиску. Применены рекомендации навыков frontend-design и ui-ux-pro-max по иерархии, состояниям поиска, доступности и постепенному раскрытию.
